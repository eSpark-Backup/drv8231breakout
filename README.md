# DRV8231 Breakout Board
#### Client Name: Cole Benson

## Project Requirements
- Create a breakout board based on DRV8231 IC that can essentially serve a commercial purpose as well:
    - The breakout should contain the DRV8231 IC and supporting circuitry.
    - It should contain headers to connect an external MCU (STM32, Arduino, ESP32 etc etc)
    - It should also contain means to allow testing of LSS Pro Gripper as a standalone additional feature to allow for commercial reach.
         - Encoder Power etc for 2 channel encoder present in LSS Pro Gripper setup
    - The breakout board should contain 4 mounting holes on all 4 edges standard sizing.
